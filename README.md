# DZFZ / DZXG - ZWCAD AutoLISP

当前版本：1.0.0

## 命令

### DZFZ - 文字递增复制
1. 输入 `DZFZ`。
2. 选择一个末尾带数字的 TEXT 或 MTEXT 作为模板。
3. 指定复制基点。
4. 输入递增步长，默认 1。
5. 每次点击目标位置，创建一个副本；按 ESC 结束。
6. 原对象不会被修改。

例如模板为 `KIM-HB01L1S1`，步长为 1，依次放置生成 `...S2`、`...S3`、`...S4`。

### DZXG - 文字递增修改
1. 输入 `DZXG`。
2. 依次点击 TEXT 或 MTEXT 对象。
3. 输入递增步长，默认 1；第一个对象作为编号起点，后续对象按点击顺序递增。
4. 按 ESC 结束。

## 编号规则
- 只识别文字末尾连续的 ASCII 数字。
- 文字中间的数字不变。
- 默认递增步长为 1。
- 保留数字位数的前导零，例如 `FAT009` + 1 = `FAT010`；超过位数时自动扩展，例如 `FAT999` + 1 = `FAT1000`。
- 对不带末尾数字的对象跳过或提示。

## 加载
在 ZWCAD 命令行输入 `APPLOAD`，选择 `DZFZ.lsp`。加载后输入 `DZFZ` 或 `DZXG`。

## 兼容性说明
首版提供 AutoLISP 源码（LSP），以 ZWCAD 的 AutoLISP/Visual LISP 兼容环境为目标。当前未提供 VLX 编译文件；VLX 需要在目标 CAD 环境中验证编译兼容性。

## 测试提示
建议先在图纸副本中测试 TEXT、MTEXT、不同文字样式、旋转文字和带格式控制符的 MTEXT。首版对 MTEXT 使用实体 DXF 的组码 1 文字串进行尾缀处理；复杂分段格式的 MTEXT 建议重点验证。
